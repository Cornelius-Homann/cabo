📖 Quick Reference Sheet

Create / Overwrite: set(ref, data)

Overwrites everything at the target path.

Update Fields: update(ref, { key: value })

Updates specified fields without deleting existing siblings.

Append List Item: push(ref, data)

Generates a unique timestamped key like -O9Xk....

Delete: remove(ref) or set(ref, null)

Deletes the node at that location.

Atomic Tx: runTransaction(ref, (val) => val + 1)

Prevents race conditions when multiple players update simultaneously.
